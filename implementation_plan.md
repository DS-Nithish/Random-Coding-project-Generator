## Step 1: Analyze the User's Request
- The user wants a project that can generate random projects for them to work on.
- The project should be able to generate projects for different skill levels ( beginner, intermediate, advanced).
- The project should also be able to generate projects for different domains (web development, mobile app development, game development, etc.).

## Step 2: Generate Project Ideas
- Generate 10 project ideas for each skill level and domain.

## Step 3: Generate Project Details
- For each project idea, generate details such as:
    - Project title
    - Project description  
    - Project requirements
    - Project technologies
    - Project duration
    - Project difficulty

## Step 4:Generate Project steps , project code and project documentation only if the user explicitly asks for it.

## Step 5: Generate Project Steps
- For each project idea, generate steps to complete the project.

## Step 6: Generate Project Code
- For each project idea, generate code to complete the project which should be self-contained in a single file.

## Step 7: Generate Project Documentation
- For each project idea, generate documentation such as:
    - Project README
    - Project documentation
    - Project demo
    - Project deployment
